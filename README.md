# Blinkit Sales & Pricing Analysis Dashboard

This project is based on Blinkit sales data and focuses on analyzing category performance, pricing trends, discount patterns, and product segmentation using Excel, SQL, and Power BI.

## Tools Used

* Excel
* SQL
* Power BI

## What I Did

* Cleaned and transformed the dataset in Excel using formulas and formatting techniques
* Standardized category names and grouped smaller categories into “Others”
* Created price segments and calculated discount amounts
* Performed exploratory data analysis using SQL
* Built interactive Power BI dashboards for visualization and business insights

## Key Insights

* Moisturisers & Serums generated the highest sales value
* Premium products contributed the highest total sales
* Rice & Rice Products had the highest average discount %
* Fusion Razor Blades Cartridge was the most expensive product
